[TRE-INVERSIÓN]

Detección de Cuerpos Cavernosos

⚡ Inversión 2D 🐍 ResIPy + Python 🕳️ Alta resistividad

Inversión de múltiples líneas de TRE para detectar cuerpos cavernosos de alta resistividad en el subsuelo. Procesamiento avanzado con ResIPy, scipy, numpy y librerías científicas de Python.

[INVESTIGACIÓN]

TERRAF - Sistema Integrado de Prospección Mineral

🐍 Python 🛰️ GEE 🧲 Geofísica 🤖 ML

Plataforma Python para exploración mineral que combina métodos geofísicos (magnetometría, gravimetría, inversión 3D) y teledetección satelital (Landsat, Sentinel-2) vía Google Earth Engine. Incluye deconvolución de Euler, inversión de susceptibilidad magnética, cálculo de índices espectrales (CMR, GOSSAN, óxidos de hierro) y machine learning para mapas de prospectividad mineral. Stack: NumPy, SciPy, Pandas, Streamlit, Folium, GeoPandas, Google Earth Engine API.

🚀 APP TERRAF
EN DESARROLLO 2025
[SEV-HIDROGEOLOGIA]

Sondeos Eléctricos Santo Tomás de las Flores

💧 Acuífero 🐍 VESpy 📉 Savitzky-Golay

Sondeos Eléctricos Verticales para identificar zonas con potencial acuífero en Santo Tomás de las Flores, Estado de México. Procesamiento con VESpy: filtrado Savitzky-Golay e inversión para localizar unidades hidrogeológicas favorables a la perforación de pozos.

COMPLETADO 2024
[GPR-ARQUEOLOGÍA]

GPR República de Perú 57, Centro Histórico CDMX

🏺 Arqueología 📡 600/200 MHz 🗺️ 3 mallas

Estudio GPR para detectar estructuras arqueológicas antiguas (mexica/novohispana) en el Centro Histórico de la CDMX. Antenas duales 600 y 200 MHz, 3 mallas de medición con interpolación Kriging y mapas de profundidad. Evaluación de viabilidad de una bodega subterránea sin afectar el patrimonio cultural.

COMPLETADO 2024
[OPEN-SOURCE]

hvsrlearn Development

🐍 Python 📈 HVSR 🖥️ GUI

Herramienta open-source para procesamiento de ruido sísmico ambiental con la técnica de Razón Espectral Horizontal/Vertical (HVSR). Incluye interfaz gráfica para picking e interpretación de microtrepidaciones.
